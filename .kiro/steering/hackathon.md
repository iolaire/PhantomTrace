# Hackathon

PhantomTrace is a Kiroween 2026 entry in the Resurrection category. The deadline is December 4, 2026, 2:00 pm Pacific Time. Full rules: `docs/Hackathon/Rules.md`. Checklist: `docs/SubmissionChecklist.md`.

## Repository rules

- Never add `.kiro/` or its subfolders to `.gitignore`. Doing so can disqualify the submission.
- The repository stays public on GitHub with the MIT `LICENSE` at the root.
- All source, assets, and run instructions stay in the repository.
- Disclose any pre-existing code or templates in the README.
- Use third-party SDKs, APIs, and data only within their licenses.

## Demo and media

- Demo video is under 3 minutes, public on YouTube, and shows the app running on a Mac.
- No third-party trademarks or copyrighted music or material without permission.
- All submission material is in English.

## Judging criteria

Impact, Technological Implementation, Design, Innovation, and Presentation are weighted equally. Keep `docs/KiroUsage.md` current with real evidence of specs, steering, hooks, and property-based testing.
